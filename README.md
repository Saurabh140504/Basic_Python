Python Mini Projects – Banking System & Marksheet Generator
Overview

This repository contains two Python-based mini projects developed to strengthen fundamental programming concepts and apply them to practical use cases. Both projects are console-based applications designed using core Python without any external libraries.
The purpose of these projects is to demonstrate understanding of basic programming logic, control structures, functions, and user interaction handling.

Projects included in this repository:

Banking System
Marksheet Generator

1. Banking System
Project Description
The Banking System is a menu-driven Python application that simulates basic banking operations. It allows users to perform essential banking tasks through a command-line interface.
Key Features
Create a new account
Deposit money
Withdraw money with balance validation
Check account balance
Input validation and error handling
Structured and logical program flow

Concepts Used
Conditional statements (if-else)
Loops (while)
Functions
User input handling
Basic financial logic implementation

2. Marksheet Generator
Project Description
The Marksheet Generator is a Python application that calculates total marks, percentage, and assigns grades based on user input. It provides a formatted marksheet output in the console.
Key Features

Accept student name and subject marks
Calculate total marks
Compute percentage
Automatically assign grade based on percentage
Display structured output
Grading Criteria
90% and above – Grade A
75% to 89% – Grade B
60% to 74% – Grade C
40% to 59% – Grade D
Below 40% – Fail

Concepts Used

Arithmetic operations
Conditional grading logic
Input validation
Output formatting

Technologies Used
Python 3
No external libraries required

Learning Outcomes
Through these projects, the following programming concepts were reinforced:
Logical thinking and problem-solving
Writing modular and readable code
Implementing real-world scenarios using basic Python
Handling user interaction in console applications
